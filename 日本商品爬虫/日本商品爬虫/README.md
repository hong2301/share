# 乐天リーメント商品爬虫项目

## 📋 任务概述

从乐天书店（Rakuten Books）抓取**リーメント（RE-MENT）**品牌的所有商品信息。

### 目标网站
- 店铺：リーメント官方店铺
- 链接：https://books.rakuten.co.jp/search?seller=リーメント
- 商品总数：约 900 个

---

## 🎯 需求详情

### 需要抓取的数据字段

| 字段 | 说明 | 示例 |
|------|------|------|
| 商品ID | 乐天商品编号 | 18722309 |
| 商品名称 | 完整标题 | どうぶつの森 Happy Room2 【6個入りBOX】 |
| 分类 | 商品类别 | グッズ/玩具 |
| JAN码 | 商品条码 | 4521121700854 |
| 发售日 | 发售日期 | 2026年11月下旬 |
| 品牌 | リーメント | リーメント |
| 原价 | 参考小売価格 | 9,900円 |

| 现价 | 实际售价（税込） | 7,623円 |


---

## 🚀 使用方法

### 1. 抓取基础数据（已完成）

```bash
python3 scrape_fast.py
```

输出：`商品数据_基础.xlsx` + `商品数据_基础.json`

### 2. 补充详情页数据（待执行）

```bash
python3 scrape_details.py
```

输出：`商品数据_完整.json`（包含商品说明、款式列表）

### 3. 下载缩略图（可选）

```bash
python3 download_thumbnails.py
```

输出：`缩略图/` 目录，按商品ID命名
