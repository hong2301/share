# JSON数据提取说明

## 6个数字字段

从 `raw` 字段中提取以下6个数字：

| 序号 | 字段名 | 路径 | 说明 |
|------|--------|------|------|
| 1 | totalFundsGathered | raw.projectState.statistics.totalFundsGathered | 总筹款额 |
| 2 | totalBackersCount | raw.projectState.statistics.totalBackersCount | 总支持者数 |
| 3 | backersCount | raw.projectState.statistics.backersCount | 支持者数 |
| 4 | fundsGathered | raw.projectState.statistics.fundsGathered | 已筹款额 |
| 5 | completionRate | 计算值 | 完成率 = fundsGathered / campaignGoal × 100% |
| 6 | campaignGoal | raw.projectContext.project.campaignGoal | 目标金额 |

## 提取代码示例

```python
raw = json_data.get('raw', {})
statistics = raw.get('projectState', {}).get('statistics', {})
project_context = raw.get('projectContext', {}).get('project', {})

total_funds_gathered = statistics.get('totalFundsGathered', 0)
total_backers_count = statistics.get('totalBackersCount', 0)
backers_count = statistics.get('backersCount', 0)
funds_gathered = statistics.get('fundsGathered', 0)
campaign_goal = project_context.get('campaignGoal', 0)

# 计算完成率
if campaign_goal > 0:
    completion_rate = f"{(funds_gathered / campaign_goal * 100):.2f}%"
else:
    completion_rate = "0.00%"
```
