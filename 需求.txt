二、采集字段
──────────────────────────────────────────────────────

  每个商品需采集以下字段，最终输出为一张 Excel 表格（.xlsx）：

  ┌──────┬────────────────────┬────────────────────────────────────────────┐
  │ 序号 │ 字段名             │ 说明                                        │
  ├──────┼────────────────────┼────────────────────────────────────────────┤
  │  1   │ 店铺名称           │ 对应当前商品的所属店铺                       │
  │  2   │ 商品链接           │ 商品详情页完整 URL                          │
  │  3   │ 商品名             │ 商品标题（完整标题，不要截断）               │
  │  4   │ 颜色分类           │ SKU 维度，如"白色""黑色""标准款"等           │
  │  5   │ 价格（原价）       │ 划线价 / 原价（非券后价），没有则留空         │
  │  6   │ 商品参数-xxx       │ 见下方说明，每个参数独立一列                 │
  │  …   │ 商品参数-yyy       │ 不同店铺/类目参数名不同，随店铺动态生成      │
  │  …   │ …                 │ …                                           │
  │  n   │ 商品图片本地路径   │ 图片保存到本地文件夹后的相对路径              │
  │ n+1  │ 各图片链接         │ 商品所有图片的原始 URL，多条用" | "分隔       │
  └──────┴────────────────────┴────────────────────────────────────────────┘

  关于"商品参数"的重要说明：
  · 每个参数独占一个 Excel 列，不要把多个参数挤到同一个单元格。
  · 各店铺/类目的参数名不完全相同（如尺寸、材质、适用年龄、IP角色等），
    采集时按该店铺实际展示的参数动态生成列名。
  · 同一个店铺内，所有商品的参数列名应保持一致；不同店铺之间的列可以不同，
    最终将各店铺数据分 Sheet 存放，或统一放在一张表但允许部分列为空。
  · 建议列名格式：参数-材质、参数-尺寸、参数-适用年龄 …（前缀统一便于筛选）。

三、图片采集要求 ⚠️ 重点
──────────────────────────────────────────────────────

  1. 图片格式：.jpg（统一保存为 JPEG 格式）。
  2. 图片命名：以淘宝商品 ID（item_id）为前缀，多张图片加序号后缀，
     例如：
       1234567890_01.jpg
       1234567890_02.jpg
       1234567890_03.jpg

  3. ⚠️ 图片尺寸：必须下载"大图 / 原图"，严禁下载缩略图！
     · 天猫/淘宝商品主图 URL 通常为：
        小图：  //img.alicdn.com/xxx.jpg_80x80.jpg
        中图：  //img.alicdn.com/xxx.jpg_400x400.jpg
        大图：  //img.alicdn.com/xxx.jpg              ← 目标
     · 采集时去掉 URL 末尾的分辨率后缀（如 _80x80、_400x400、_800x800），
       直接请求原始大图 URL。
     · 小图上传到其他平台后模糊不可用，务必确保拿到原始高清图。

  4. 图片保存目录结构：
        ./images/<店铺简称>/
     例如：
        ./images/popmart/1234567890_01.jpg
        ./images/52toys/9876543210_01.jpg

  5. Excel 中"商品图片本地路径"列记录相对路径，方便后续核对。

四、采集逻辑建议
──────────────────────────────────────────────────────

  1. 逐店铺、逐页翻商品列表，获取该店铺全部商品的链接。
  2. 进入每个商品详情页，抓取：
     - 商品标题
     - SKU 颜色分类列表
     - 原价（划线价）
     - 参数表格（页面上的"产品参数"区域）
     - 商品主图及详情图 URL（取原图）
  3. 参数区各店铺排版不同（有的在右侧参数栏，有的在详情描述里），需自适应。
  4. 下载图片时添加适当延时，避免触发反爬。
  5. 最终输出：
     - 一个 .xlsx 文件，包含所有店铺的商品数据（分 Sheet 或汇总在一张表）。
     - 一个 images/ 文件夹，内含各店铺子文件夹及全部商品大图。
