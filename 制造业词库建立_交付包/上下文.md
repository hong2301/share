## 一、项目概况

- **研究主题**：制造业企业**设计驱动型创新**（Design-Driven Innovation）
- **研究样本**：2017-2025 年沪深 A 股上市制造业企业（客户已提供企业清单 `制造业企业.xlsx`）
- **项目目标**：构建"设计驱动型创新"领域词典 → 对年报文本做关键词匹配计数 → 构建企业层面指标 → 实证分析（与 TFP、股票流动性、企业分工、企业价值等回归）
- **当前阶段**：种子词库 + BERT 扩词已完成，**待用年报语料做最终扩词与归一化，形成最终词典**

## 二、客户整体思路（技术路线）

1. **文本获取**：爬虫下载上市公司年报，提取 PDF 文本（此步在另一台电脑已独立完成——年报已全部下载）
2. **构建语料库**：以年报（或年报 MD&A）作为训练语料
3. **分词**：jieba 中文分词，加入自定义专业词典，保证"机器学习""深度学习"等术语不被切散
4. **训练词向量**：Word2Vec（Skip-gram）或 BERT 在年报语料上训练
5. **种子词扩词**：输入种子词，计算语料中所有词与种子词的余弦相似度，筛选 Top-K 相似词，人工剔除重复/不相关/低频词，形成最终领域词典
6. **构建企业指标**：关键词匹配计数，常用处理：
   - 关键词总数 +1 取自然对数：ln(1+关键词数)
   - 关键词词频 / MD&A 文本长度
   - 哑变量 / 累计变量等稳健性指标
7. **实证分析**：指标与 TFP、股票流动性、企业分工、企业价值等被解释变量回归，辅以内生性检验（PSM、DID、工具变量）、机制检验、异质性分析

## 四、黑名单（扩词/匹配时必须剔除，固定不变）

词典构建过程中一律剔除以下混淆词语：
**设计产能、设计压力、设计温度、设计流量、设计参数、设计工况、设计寿命、设计图纸、工程设计、勘察设计、设计院、初步设计、施工图设计、设计资质、顶层设计、制度设计、机制设计、股权设计、薪酬设计、联名担保、联名账户**（共 21 词）

其他约定：
- 词库**不含单字"设计"**，仅收二字以上复合词
- "设计研究院""工业设计研究院"因与黑名单"设计院"字面易混淆，不作为关键词保留
- 词条需可溯源（来源文件 + 原文摘录 + 语料频次），保证论文严谨性

- 方法：BERT（bert-base-chinese）词向量 = 词覆盖的字级 token embedding 均值；清洗仅保留 2-6 字中文词，剔除黑名单与无意义高频词

## 七、最后工作详细步骤（另一台电脑执行）

1. **读上下文**：先读本文件 + `说明.txt` + `扩词/扩词结果说明.md`
2. **年报语料就绪**：年报已下载（另一台电脑）。提取 MD&A 文本（如客户要求以 MD&A 为语料），构建语料库；若全文使用则全文分词
3. **全量扩词**：以 `第二次输出/种子词库_第三次输出.xlsx` 的 195 个种子词为锚点，在年报语料上做 BERT 语义扩词（Word2Vec 共现词作为第二路补充）；重点补充此前无法扩出的外观层词（材质、饰面、产品外观等）；保留"是否保留"筛选列
4. **人工/客户筛选**：客户在 Excel 筛选列标记删/留/改
5. **归一化去重**：同义合并、近义归并、包含关系处理、跨维度交叉词编码（参考《词库构建方法.doc》五阶段范式与 table3 样例），最终词典建议控制在 **600-900 个标准词**
6. **jieba 校验**：自定义词典防切散 + 词性过滤 + 人工审核补漏；黑名单 21 词 + 单字"设计"过滤
7. **构建企业指标**：对 2017-2025 年报文本做关键词匹配计数，生成 ln(1+词频)、词频/MD&A 长度、哑变量等指标面板
8. **实证分析**：与 TFP、股票流动性、企业分工、企业价值等回归 + 内生性检验（PSM/DID/IV）+ 机制与异质性分析
