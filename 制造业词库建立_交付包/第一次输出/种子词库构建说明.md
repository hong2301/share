## 五、客户筛选操作方式

在任一版本 Excel 的**"筛选意见"列**标记即可，三种写法均可：
- 填 **"删"** → 该词剔除；
- 填 **"保留"** 或留空 → 默认保留；
- 填 **"改为：XX"** → 该词替换为指定词；
- 也可直接在"备注"里写意见。

筛选完成后把文件发回，我们据此进入**扩词阶段**（以确认后的种子词为锚点，对年报语料检索变体扩词；届时同步启动年报爬虫）。

## 六、归一化方法论（为后续扩词与最终词典做准备）

参考《词库构建方法.doc》陈丽（2023）五阶段范式（初始词表—语料回溯—分词校验—专家评审—归一化去重），后续流程：

```
阶段一（本次已完成）：种子词库 264 词
阶段二：语料回溯扩词 → 以种子词为锚点在年报语料（MD&A）检索变体，预计扩至 800-1200 词
阶段三：jieba 分词校验（自定义词典防切散 + 词性过滤 + 人工审核补漏）
阶段四：专家评审（领域专家 → 实务专家 → 方法论专家，至少 3 轮）
阶段五：归一化去重与编码（同义合并/近义归并/包含关系/跨维度交叉词，编码如 3.2.01）
```

**归一化率参考**：教育方向词库 2592→819 词（31.6%），本项目最终词典建议控制在 **600-900 个标准词**。
