# 扩词结果说明（词典.xlsx 扩展版）

> 交付日期：2026-08-04
> 方法：BERT（bert-base-chinese 预训练模型）语义扩词 —— 基于对比实验（Word2Vec vs BERT）选出的最优方法

## 一、交付物

**`扩词结果_词典扩展版.xlsx`**（3 个 Sheet）

| Sheet | 内容 |
|---|---|
| **扩词明细** | 每个种子词的扩词清单：种子词 / 层级 / 维度 / 语料状态 / 扩词 / 相似度，末尾"是否保留"列供筛选 |
| **按种子词汇总** | 47 个种子词一行式汇总：BERT 扩词 Top10 + Word2Vec 参考词（不建议直接采用） |
| **合并词库** | 种子词+扩词去重后的 190 词总库：词 / 是否种子词 / 来源种子词 / 维度 / 相似度 |

## 二、方法说明

- **主方法 BERT**：bert-base-chinese 预训练模型，对语料逐句编码，词向量 = 该词覆盖的字级 token embedding 均值（全部出现位置平均）；种子词在语料中出现则用语料向量，未出现则单独编码（利用预训练语义）
- **语料**：4 份政策 + 9 篇文献全文（18.7 万字中文）
- **清洗**：仅保留 2-6 字中文词；剔除客户黑名单 21 词（设计产能、设计院等）；剔除叠字残词与无意义高频词（其二、此外、进行等）

## 五、无法扩词的 5 个种子词（客观说明）

产品外观、材质、饰面、设计评价、身份认同 —— 在当前中文语料（政策+文献）中未出现或缺乏相关语境，BERT 无法可靠扩词。

**正式扩词时需解决**：以上词属于"色彩、材质与饰面"等维度，依赖制造业年报语料（企业年报中会大量出现材质、工艺等表述）才能扩出有效词；届时 BERT 扩词 + Word2Vec 年报共现词结合，覆盖率会大幅提升。

## 六、后续流程建议

1. 客户在"扩词明细"Sheet 的"是否保留"列筛选（删/留/改）；
2. 确认后的扩词并入词库，进行归一化去重（同义合并/近义归并/包含关系处理，参考《词库构建方法.doc》）；
3. 年报语料就绪后，重复本流程做全量扩词（语料千万级 token 时，Word2Vec 可作为第二路补充）。
