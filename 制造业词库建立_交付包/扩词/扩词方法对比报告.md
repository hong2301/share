# 扩词方法对比报告：Word2Vec vs BERT

> 实验日期：2026-08-04
> 目的：客户问"词典.xlsx 扩词用 Word2Vec 还是 BERT 训练效果好"——两种方法均实际运行对比

## 一、实验设置

| 项目 | 说明 |
|---|---|
| 种子词 | 词典.xlsx 全部 47 个词 |
| 语料 | 4 份政策 + 9 篇文献全文（18.7 万字中文，13 个文件） |
| 分词 | jieba（47 个种子词加入自定义词典防切散） |
| Word2Vec | Skip-gram，vector_size=100，window=5，min_count=1，epochs=30，从头训练 |
| BERT | bert-base-chinese 预训练模型，对语料逐句编码，词向量=该词覆盖的字级 token embedding 均值（全部出现位置平均） |
| 相似度 | 余弦相似度，取 Top-8 相似词 |

## 二、结论先行

### ✅ BERT 效果明显优于 Word2Vec

| 指标 | Word2Vec | BERT |
|---|---|---|
| 种子词覆盖率 | 42/47 | 34/47 |
| 相似词语义相关性 | **差**（大量噪音词、残词） | **好**（高度领域相关） |
| 适用语料要求 | 需百万级 token，18万字严重不足 | 预训练自带语义知识，小语料可用 |

**BERT 胜出的根本原因**：
1. **预训练语义知识**：BERT 在海量中文语料上预训练，即使本项目语料小，也能利用其通用语义理解（如"色彩→造型、线条、风格、功能设计"）；
2. **语境感知**：BERT 对每个词按上下文生成向量，"意义创新→意义、创新、产品意义、创意、创新者"；
3. **领域对齐**：扩出的词与"设计驱动型创新"理论高度相关（如"设计驱动→设计驱动型创新、设计主导、设计思维、协同设计"）。

## 四、Word2Vec 效果差的客观原因

1. **语料规模不足**：18.7 万字 ≈ 几千句子，Word2Vec 需要百万级 token 才能稳定学到词分布；此规模下相似词多为"同现噪音"（如"设计投入→22%、18%、总额"这类表格数据共现）；
2. **分词噪音**：小语料中错分/残词（"浯""烯""专成业"）被当成词参与训练，污染词向量；
3. **表格/文献格式干扰**：政策文件含大量条款序号（"第七条""第十条"）、百分比（"22%""713"）等，在共现统计中产生假相关。

**注意**：这不代表 Word2Vec 方法本身差，而是**本项目当前语料规模下不适合**。客户最终会用年报语料（数千家企业×多年），届时语料可达千万 token，Word2Vec 效果会大幅改善。

## 五、对客户方案的建议

### 场景一：当前小语料（政策+文献，验证概念）
**用 BERT（bert-base-chinese 或 RoBERTa-wwm-ext）**，扩词质量高。

### 场景二：后续年报大语料（扩词正式流程）
推荐**两者结合**（与说明.txt 中客户原始方案一致，也是《管理世界》姚加权等 2024 的做法）：
1. **BERT 生成种子词的语义邻居**：利用预训练语义，找出"语义相近但表述不同"的词（解决同义/近义扩词）；
2. **Word2Vec 在年报语料上训练**：捕捉"该行业语料中实际共现"的词（解决领域专属表述，如企业年报特有的说法）；
3. **取交集/加权合并**：两路结果取并集后人工筛选（按余弦相似度阈值 + 黑名单过滤 + 人工审核），既覆盖语义相似词，又覆盖语料特有词；
4. 一致性做法可参考：吴非等 2021（数字化转型）、姚加权等 2024（人工智能）——均用机器学习生成领域词典后对年报文本分析。

### 覆盖率说明
- 47 个种子词中，BERT 有 34 个能扩词（13 个未出现：产品外观、材质、饰面、工业设计示范园区、设计组织、设计评价、设计方法、设计投入、文化符号、身份认同、设计顾问、跨行业企业、设计论坛）——这些词在政策+文献语料中未出现或频次过低，**正式扩词时需依赖年报大语料覆盖**；
- Word2Vec 覆盖率看似更高（42/47），但其中不少是低质量相似词（残词/噪音），实际可用性低。
