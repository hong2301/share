# ind 数据分类说明

## 目录结构

```
ind/
├── 0-10000/
├── 10001-20000/
├── 20001-30000/
├── 30001-40000/
└── 40001-50000/
```

## 分类规则

按数据 ID 进行分段存储，每个文件夹包含 10000 条数据：

| 文件夹 | ID 范围 | 数据量 |
|--------|---------|--------|
| 0-10000 | 0 ~ 10000 | 10001 条 |
| 10001-20000 | 10001 ~ 20000 | 10000 条 |
| 20001-30000 | 20001 ~ 30000 | 10000 条 |
| 30001-40000 | 30001 ~ 40000 | 10000 条 |
| 40001-50000 | 40001 ~ 50000 | 10000 条 |

**总计**：50001 条数据

## 使用方法

### 查找某条数据

根据数据 ID 确定所属文件夹：

```
文件夹 = floor(ID / 10000) * 10000 + "-" + (floor(ID / 10000) + 1) * 10000
```

例如：
- ID = 5000 → 文件夹 `0-10000`
- ID = 15000 → 文件夹 `10001-20000`
- ID = 35000 → 文件夹 `30001-40000`

### 批量处理

```bash
# 统计每个文件夹的数据量
for dir in ind/*/; do
    count=$(ls -1 "$dir" | wc -l)
    echo "$(basename $dir): $count 条"
done
```

## 注意事项

- 每个文件夹独立，便于分批处理和备份
- ID 范围是连续的，确保没有遗漏
- 新增数据时，根据 ID 自动分配到对应文件夹
